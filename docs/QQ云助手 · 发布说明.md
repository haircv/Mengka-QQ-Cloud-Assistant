# QQ云助手 · 发布说明

**萌卡 NT 3.0 原生 IPC 插件 · 本地卡密授权 · 382 条指令 · 59 个控制台模块 · v1.2.19**

------

## 特点

- 本地卡密授权：卡密、分群授权、代理配额，全部落本地 SQLite，无授权站、无应用 ID、无心跳、无远程校验、无到期退群
- 原生 IPC：`native-ipc-v1`，随框架启动，不占端口、不配 Token
- 自带 Web 控制台：59 个模块，默认 `127.0.0.1:18084`，原生 HTML/JS，无 CDN
- 默认仅主人：全部指令默认 Lv5（含菜单/帮助/状态），控制台三档预设一键调整
- 自身即主人：机器人自己发消息直接 Lv5，免疫黑名单
- 多账号多协议：全链路 `self_id + protocol_id` 双键，`protocol_id=0` 有效；同 QQ 多协议在线时默认仅 Android 实例生效
- 红包助手：普通/拼手气/口令/专属/语音五类自动领取，凭据失效自动重查重试；语音红包内置 AI 语音，可选自定义 TTS 或固定音频，关键词包含/排除、期望收益过滤、到账回复、账本与排行
- 在线更新：GitHub Release 检查、SHA256 校验、萌卡管理员会话导入，服务节点自动选择，导入后自动启用插件
- 一份源码三平台：Windows x64 / Linux x86_64 / Linux ARM64，纯 Go 无 cgo

## 权限

```
0 黑名单 / 1 群员 / 2 管理 / 3 群主 / 4 分管 / 5 主人
```

- 全部指令默认 Lv5，可配置范围 1–5，`0` 仅黑名单
- 覆盖优先级：群级 > 全局指令 > 全局类目 > 默认 5
- 显式例外：红包群配置/状态/排行、`使用卡密`/`查询授权` 为 Lv3；`生成卡密`/`查询卡密` 为 Lv1 但处理器只允许主人或代理
- 自动功能只受开关、名单与授权门禁控制，不受指令级别限制
- 自身消息按 Lv5 处理，但不进入问答/艾特/表情回应/防撤转发
- 授权门禁默认关闭；开启后只拦截未授权群的指令，Lv5 与授权类指令豁免

## 安装

1. 下载对应平台包，解压到空目录（含 `mengka-plugin.json` + 可执行文件）
2. 萌卡 NT 控制台导入插件包，绑定节点
3. 启动后看 stderr 输出的控制台地址与首次令牌
4. 浏览器打开 `http://127.0.0.1:18084`，`admin` + `admin.token` 登录
5. 添加主人 QQ → 选“推荐”权限预设 → 配置群功能 → 发“菜单”验证
6. 需要授权门禁时，在“授权 → 授权设置”开启，并在“卡密管理”生成卡密；群主在群内发送 `使用卡密 <卡密>` 开通
