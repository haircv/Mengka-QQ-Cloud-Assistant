# QQ云助手 v1.2.23

## 更新内容

- 运行状态指令内存显示修正：
  - 现在显示 `内存：已用 X / 总量 Y（占率 Z%）`。
  - 不再出现把总量当作已用大小展示的问题。
- 移除“重新安装当前版本”功能：
  - 在线更新只在发现更高版本时允许安装；已是最新时按钮不可用。
  - 后端同样拒绝安装同版本，避免萌卡返回“更新包版本必须高于当前插件版本”。
- 保留下载自动重试、提交后页面自动刷新、启动助手和自动启用日志。

## 升级说明

- 已安装 1.2.21/1.2.22：在“系统 → 在线更新”检查并安装 1.2.23。
- 1.2.20.1 不符合萌卡版本格式，已废弃。
- 配置、日志、授权与红包账本保留。
