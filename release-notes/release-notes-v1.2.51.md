# QQ云助手 v1.2.51

## 更新内容

- 新增「助手」分区与控制台页面（共 61 个模块、399 条指令）：
  - 农场助手：最多 8 台农场服务器管理（名称/地址/账号/密码或访问 Code）、推送目标单选、连接测试；推送设置（间隔、临期提前刷新、仅推指定 QQ、已在线跳过、更新后 /start、bot_online 即时推送、Android/Linux 开关）；QQ 账号状态表（在线状态、昵称、等级、农场绑定、自动推送开关、农场侧状态、单号推送）。
  - 农场取码优先官方 `get_qq_farm_code`（Android），失败回退旧版 `get_qq_classic_farm_code`；按账号绑定农场 id，code 未变化或已在线时跳过；服务器凭据 AES-256-GCM 加密落盘，登录 code 不写日志、不持久化明文。
  - 农场聊天指令：`农场推送`、`农场全部推送`、`农场状态`、`开启农场推送`、`关闭农场推送`（默认 Lv5）。
  - 加速助手：目标账号选择、任务面板读取与勾选、框架每日定时执行保存、立即执行选中任务、最近执行结果（以 confirmed 为准）；自动补挂（每日定时、延后重试、跳过任务名单、未开调度自动开启）、批量补挂全部安卓账号、单账号补挂。
  - 加速聊天指令：`补挂加速 [QQ]`、`批量补挂`、`查询加速 [QQ]`、`任务开关`、`切换加速任务`、`设置加速时间`、`电脑登录`、`开启/关闭重登`、`开启/关闭自动补挂`、`设置补挂时间`（默认 Lv5）。
  - 框架 `level_task_settings` 仍为唯一调度数据源；插件自动补挂与框架定时执行相互独立。
- 优化插件信息获取：以本地 `mengka-plugin.json` 清单 + IPC 握手 ready 字段为能力基线，不再硬依赖框架 `get_plugin_context`；远程上下文仅作可选补充，缺失或失败不影响指令注册。
- 同步更新 README、开发文档与三平台安装包。

## 升级说明

- 重新导入 1.2.51 并启动；已有数据目录的配置、卡密、红包账本与农场/加速设置均保留。
- 农场助手需先在「助手 → 农场助手」新增至少一台服务器并保存，才会开始推送。
- 加速助手仅 Android 协议账号可用；Free 会员不可用、Plus 要求 QQ 等级 ≥ 32。
