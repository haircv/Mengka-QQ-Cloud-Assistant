# QQ云助手 v1.2.14

## 更新内容

- 修复在线更新提示“萌卡未接收更新：请选择服务节点”：导入前自动读取 `/api/v1/nodes/options`，优先匹配萌卡托管节点；仅一个可用节点时自动选择，多节点时可在“在线更新设置 → 服务节点 ID”填写。导入表单补全 `node_id` 与 `trusted_source_ack`。
- 在线更新设置新增“服务节点 ID（可选）”，留空时自动选择。
- 数据目录优先使用萌卡注入的 `MENGKA_PLUGIN_DATA_DIR`，插件更新、暂停、重新导入时不再因程序目录变化而清空数据库、配置、授权与日志。
- 当托管数据目录为空时，自动从原用户配置目录或旧版 `data/` 迁移数据；迁移前生成 `.pre-migrate-*` 备份，迁移失败时继续使用原目录，避免二次丢失。

## 升级说明

- **1.2.13 及更早版本必须手动导入一次 1.2.14**：旧版的在线更新不会提交 `node_id`，仍会被萌卡拒绝为“请选择服务节点”。从 Release 下载 `qq-cloud-assistant-1.2.14-<平台>` 并在萌卡插件导入页选择节点导入即可。
- 手动导入前，如果旧数据仍保存在插件安装目录的 `data/` 中，请先备份该目录；导入后首次启动 1.2.14 会自动查找并迁移到萌卡数据目录。
- 升级到 1.2.14 后，后续在线更新会自动提交服务节点；多节点环境可在“在线更新设置 → 服务节点 ID”填写节点 ID（通常为 `1`）。
- 首次启动 1.2.14 会把原数据迁移到萌卡数据目录；配置、授权、红包账本与日志均保留，原目录备份不会被删除。
