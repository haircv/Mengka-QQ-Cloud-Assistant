# QQ云助手 v1.2.17

## 更新内容

- 点歌搜索开关联动：
  - `开启点歌功能` 现在会同时开启 `music.search_enabled`（允许外部搜索），解决“已开启点歌但仍提示搜索已关”。
  - 卡片/语音点歌在搜索关闭时不再静默回退链接，改为明确提示开启“允许外部搜索”或发送 `开启点歌功能`。
- 禁言/解禁与 @ 目标解析：
  - 支持 `禁言 @成员 60`、`禁言 @QQ号 60`、`禁言 QQ号 60`，解禁同理。
  - @ 段缺少数字 ID 时，依次回退：@ 数值 → UID 映射 → 群名片/昵称匹配 → 引用消息发送者。
  - 踢人、上下管也使用相同的目标解析；解析失败会输出 `目标解析失败` 日志，包含消息段类型与字段名，不记录敏感内容。
  - 兼容 `mention` 类型、扁平 at 数据及更多 `uin/user/qq/target` 字段变体。
- 同 QQ 多协议优先级：
  - 同一 QQ 的 Android 与 Linux/PC 同时在线时，默认仅 Android 实例处理事件，Linux/PC 实例静默，避免重复回复、重复抢红包。
  - Android 离线后，Linux/PC 自动恢复处理。
  - 账号级开关“同QQ多协议仅 Android 生效”默认开启，可在控制台“触发模式”关闭。
- 发布产物继续只保留当前版本安装包；GitHub README、开发文档与发布说明同步更新。

## 升级说明

- 已安装 1.2.16 的节点可直接在线更新到 1.2.17；导入完成后会自动启动插件。
- 升级后如点歌仍提示搜索关闭，请在群内重新发送一次 `开启点歌功能`，或在控制台点歌模块开启“允许外部搜索”。
- 多协议静默默认开启；如需 Linux/PC 也响应，在“触发模式”关闭对应开关。
- @ 解析仍失败时，请查看日志中的 `目标解析失败 ... segments=...`，把该行发给开发者即可继续定位。
