# QQ云助手 v1.2.44

## 更新内容

- 按官方“进程已启动 / 业务已配置”语义调整健康状态：
  - `configured` 在 IPC ready 前返回 false，ready 后返回 true；`ready` 始终表示管理端进程已开始监听。
  - 健康响应继续同时提供顶层/`data` 嵌套/大小写别名，并合并 ready 身份字段。
  - 令牌校验通过时回显 `X-Mengka-Managed-Token`，兼容可能校验管理端令牌的框架版本。
- 同步更新 README、开发文档与三平台安装包。

## 升级说明

- 重新导入 1.2.44 Windows 包，重启萌卡框架后启动。
- 观察启动后约 20 秒是否仍被停止；若仍失败，请保留 1.2.42 作为可用回退。
- 如果仍提示未就绪，请提供 `GET /api/v1/plugins/managed` 的响应 JSON（已提供）和萌卡框架控制台报错。
