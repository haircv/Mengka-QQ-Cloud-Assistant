# QQ云助手 v1.2.10

## 更新内容

- 群配置、提示功能增加模板变量说明；支持 `{nick}`、`{uin}`、`{uid}`、`{group}`、`{group_name}`、`{operator}`、`{target}`、`{self_id}`、`{protocol_id}`、`{time}`。
- 分管、群黑名单、全局黑名单新增/编辑只填写 QQ，不再显示或要求 UID、备注。
- 修复清屏、召唤人数、点歌模式/来源指令与 Web 控制台作用域不一致的问题；指令现在写入当前群配置。
- 禁言/解禁指令不再因节点动作权限探测而被隐藏；支持 `禁言 @成员 秒`、`禁言 QQ 秒`、`解禁 @成员`、`解禁 QQ`，动作未授权时返回明确提示。
- 定时任务新增/编辑弹窗改为内容区滚动、底部操作按钮固定，短屏和窄屏不再遮挡。
- “通用功能”新增 `在线更新`、`检查更新`、`立即更新` 指令；检查更新直接复用 Web 控制台更新服务，需要管理员验证码时提示打开控制台。
- 指令总数 380 条。

## 升级说明

在控制台“系统 → 在线更新”检查到 1.2.10 后登录萌卡管理员并导入；也可手动导入对应系统的 `qq-cloud-assistant-1.2.10-managed-native-*` 安装包，保留原数据。
