# QQ云助手 v1.2.48

## 更新内容

- 清理插件日志中的管理端逐请求记录：
  - 不再输出“萌卡管理端请求”“萌卡健康探活”“萌卡管理端控制”等高频日志。
  - 保留启动时的管理端配置、监听地址和挂载前缀日志。
- 首次启动日志补充管理令牌：
  - 首次生成 `admin.token` 时输出 `admin / <令牌>` 及 `admin.token` 的绝对路径。
  - 后续启动不重复输出令牌内容，避免泄露；可在数据目录读取 `admin.token`。
- 同步更新 README、开发文档与三平台安装包。

## 升级说明

- 重新导入 1.2.48 并启动；已有数据目录不会重复打印令牌。
- 需要查看首次令牌时，删除/备份旧数据目录后首次启动，或直接读取数据目录的 `admin.token`。
