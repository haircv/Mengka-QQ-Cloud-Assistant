# QQ云助手 v1.3.0

## 更新内容

- 修复插件导入被拦截：清单不再声明当前 API 已不存在的 `get_plugin_context`（萌卡导入校验报“插件声明的 Action get_plugin_context 不属于当前 API”），并移除对应的远程调用与合并逻辑；插件信息完全以本地 `mengka-plugin.json` 清单 + IPC 握手 ready 字段为准。声明 Action 由 72 个减至 71 个，指令仍为 399 条、控制台 61 个模块。
- 农场助手适配 Linux：官方 `get_qq_farm_code` 现在 Android 与 Linux 协议均可取码，`client_type` 随候选协议（android/linux）；旧版 `get_qq_classic_farm_code` 兜底不变。新安装默认同时推送 Android 与 Linux/PC（已有配置保持原值，可在推送设置中调整）。
- 农场/加速助手控制台 UI 优化：
  - 农场页新增总览指标（服务器数与当前目标、QQ 账号与萌卡在线、农场在线/临期、最近推送结果），服务器与推送设置宽屏双列排布，当前目标服务器带徽标，推送结果以徽标展示。
  - 加速页目标账号指标改为中文状态并上移等级/总加速/在线状态，任务面板新增全选/仅未完成/清空与已选计数，最近执行结果合并状态列，任务与结果宽屏双列排布。
- 版本号规则：固定 `x.y.z`，`y` 最高迭代到 10、`z` 最高迭代到 20，超限进位（本版由 1.2.51 进位为 1.3.0）。
- 同步更新 README、开发文档与三平台安装包。

## 升级说明

- 重新导入 1.3.0 并启动；已有数据目录的配置、卡密、红包账本与农场/加速设置均保留。
- 1.2.51 及更早版本若被导入校验拦截，直接导入本版即可。
- 农场助手需先在「助手 → 农场助手」新增至少一台服务器并保存，才会开始推送；Linux/PC 推送开关默认仅对全新配置开启。
- 加速助手仅 Android 协议账号可用；Free 会员不可用、Plus 要求 QQ 等级 ≥ 32。
