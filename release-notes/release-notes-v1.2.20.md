# QQ云助手 v1.2.20

## 更新内容

- 群管提示默认关闭：
  - 入群提示、退群提示、被踢提示、机器人被踢提示默认值全部改为关闭。
  - 被删通知（好友关系被移除）全局默认也改为关闭。
  - 需要在单个群开启时，进入“群管理 → 提示功能”选中对应群打开开关，或在群内发送 `开启入群提示`、`开启退群提示`、`开启被踢提示`、`开启被踢通知`。
  - 开启只写入当前群配置，其他群保持关闭；已经显式开启过的群不受影响。
- 在线更新自动启用增强：
  - 启动助手优先通过 Windows 任务计划或 Linux `systemd-run` 启动，避免插件替换时连同子进程一起终止。
  - 系统计划任务不可用时自动回退到独立进程。
  - “在线更新”页新增“自动启用日志”，可查看助手创建、等待版本、提交启动和失败原因。
- 运行状态统计修正：
  - 新增 CPU 占用率、系统内存已用/总量/占比、磁盘总量/剩余。
  - 保留 Worker、协程、进程内存和指令数；能力页把“管理 API 版本”与 Action/事件数量分开显示。
  - 运行概览账号数按 QQ 去重、群聊按群号去重，并单独显示协议实例数，避免同 QQ 多协议重复计数。
- 关于页版本号改为从后端实时读取，不再写死。
- 保留 1.2.19 的 CSRF 自动补发/重试、1.2.18 的红包嵌套请求。

## 升级说明

- 在线更新到 1.2.20 后，未单独开启过提示的群将不再发送入群/退群/被踢提示。
- 逐群开启后立即生效，无需重启。
- 入群欢迎属于“群配置 → 入群欢迎”的独立开关，本次未改动。
- 从旧版本升级到 1.2.20 后如仍未自动启用，手动启动一次即可；后续更新会通过系统任务计划启动助手，不再依赖旧插件进程存活。
- GitHub 发布仓库仅保留 README 与 release-notes，不再上传 `docs/` 开发文档目录。
