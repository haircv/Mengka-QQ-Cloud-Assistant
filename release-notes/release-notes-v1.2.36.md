# QQ云助手 v1.2.36

## 更新内容

- 继续修复萌卡启动约 20 秒后插件被终止的问题：
  - 1.2.35 已确认萌卡轮询 `GET /api/managed/health`，但固定 JSON 响应仍未被部分萌卡版本的裸 Go 探活客户端接受。
  - 1.2.36 在启动探活窗口内按 5 次一组轮换 12 种常见格式：纯文本 `ok`、`OK`、`healthy`，最小 JSON（`status`/`ok`/`healthy`/`success`），带版本与嵌套 `data` 的 JSON，以及 HTTP 204。
  - 任一格式被萌卡接受后会停止轮询，插件保持运行；日志记录“萌卡健康探活格式 #N”，便于确认实际命中的格式。
  - 宽 JSON 响应额外包含 `managed/admin/web`、`transport`、`node_id`、`instance_id` 等身份字段。
- 该接口仍不需要登录，且不写入高频探活日志。
- 同步更新 README、开发文档与三平台安装包。

## 升级说明

- 插件当前被萌卡停止时，请重新导入 1.2.36 Windows 包并启动。
- 启动日志出现 `萌卡健康探活格式 #N` 后，若约 20 秒内没有出现退出/停止，说明健康检查已通过。
- 然后从插件卡片点击“管理”进入控制台。
- 如果仍被停止，请提供启动后 20 秒内的完整日志，特别是最后一条“萌卡健康探活格式 #N”。
