# QQ云助手 v1.2.13

## 更新内容

- 修复 @ 消息段识别：兼容事件中的 `user_id`、`uin`、`qq`、`target_uin` 字段，禁言、解禁、踢人、上下管、头衔等所有依赖 @ 的指令均可正确取得目标 QQ。
- 点歌音频：网易云卡片改用稳定的 `song/media/outer/url` 音频地址；QQ 音乐新增 vkey 直链解析；语音失败继续使用 Base64 回退。
- 点歌卡片：页面地址、音频、封面统一使用可直接签名的地址；卡片签名失败时保留详细上游错误日志。
- 包含 1.2.12 的萌卡管理请求头修复（`X-MKNT-Web-Request`、`Sec-Fetch-*`）。

## 升级说明

在控制台“系统 → 在线更新”检查到 1.2.13 后登录萌卡管理员并导入；也可手动导入 `qq-cloud-assistant-1.2.13-*` 安装包，保留原数据。
