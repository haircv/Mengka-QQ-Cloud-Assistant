# QQ云助手 v1.3.5

## 更新内容

- **修复「指令权限」页没有可操作选项**：权限表此前被当成只读表，整页没有任何按钮。现改为「仅可改值」——每行对应一条已注册指令，提供 **编辑** 按钮下调/上调级别（1–5），类目与指令键只读、不可增删；页面顶部新增 **严格（全部 Lv5）** 与 **推荐（常用降级）** 两个一键预设。严格预设把全部指令恢复为 Lv5，推荐预设把菜单、帮助、打卡、头衔、互赞、点歌等常用指令降级到合适级别。
- **修复「菜单 配置」报「未找到类目[配置]」**：类目解析由精确匹配改为 **精确 → 忽略大小写子串 → 唯一命中** 三级回退，`菜单 配置`、`菜单 群管` 等简写现在能正确定位到对应类目。命中多个类目时列出候选名供选择，完全未命中时回复「未找到类目「X」。可用类目：…」而不是直接报错。
- **基本群管新增群公告与群精华消息指令**（共 6 条）：
  - `查询群公告`、`发布群公告 <内容>`（可附带图片）、`删除群公告 <公告ID>`；
  - `查询群精华`、`设置群精华 [消息ID]`、`删除群精华 [消息ID]`（回复消息或指定消息 ID 均可）。
  - 按官方契约核实：**删除群精华 = `set_group_essence` 置 `enabled:false`**（官方无独立删除接口）；群公告查询返回数组，发布/删除/精华设置返回 `data.success`。控制台「基本群管」模块同步新增 6 个操作按钮。
- 清单 action 由 **59 增至 64**（新增 `get_group_notice`、`send_group_notice`、`delete_group_notice`、`get_essence_msg_list`、`set_group_essence`，全部可在官方 API 索引 mengka.net/nt/api/ 查证）；指令由 **399 增至 405**；控制台模块（61）、权限体系与既有数据均不变。

## 升级说明

- 已安装 1.3.4 及更早版本可在线更新或手动导入 1.3.5。
- 已有数据目录的配置、卡密、红包账本与农场/加速设置均保留；指令权限的既有自定义级别不受影响。
- 群公告/群精华指令默认 Lv5，需要群主或主人使用时在「权限 → 指令权限」下调对应指令，或把 QQ 加入主人。
- 群公告与群精华依赖萌卡官方对应 action，节点缺少能力时相关指令不会注册，控制台会显示原因。
- 控制台为纯静态构建产物，更新后若浏览器缓存旧页面，请强制刷新一次（Ctrl+F5）。
