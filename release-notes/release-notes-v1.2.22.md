# QQ云助手 v1.2.22

## 更新内容

- 版本号保持萌卡要求的 `x.y.z` 三段格式。
- 在线更新下载自动重试：单次 90 秒超时，最多 3 次，间隔 3/6 秒，降低 GitHub 网络波动导致的“下载安装包失败”。
- 提交更新后控制台自动检测插件重启并刷新页面，不再需要手动刷新判断是否已经启动。
- 启动助手首次检查 3 秒、轮询间隔 1 秒、最多等待 3 分钟。
- 同版本重装时优先选择“同版本但已停止”的新实例，避免把仍在运行的旧实例误判为已启动。
- 从 1.2.21 更新时，旧版助手只匹配新版本 1.2.22 实例，避免同版本歧义。

## 升级说明

- 已安装 1.2.21：在“系统 → 在线更新”检查并安装 1.2.22。
- 1.2.20.1 不符合萌卡版本格式，已废弃；请使用 1.2.22。
- 配置、日志、授权与红包账本保留；更新后如未自动启用，可查看“自动启用日志”。
