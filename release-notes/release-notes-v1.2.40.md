# QQ云助手 v1.2.40

## 更新内容

- 按萌卡官方文档 `plugin-extension-v2` 修正管理端健康契约：
  - 官方要求 `/api/managed/health` 返回 `ready` 和 `configured`，用于区分进程已启动与业务已配置。
  - 此前 1.2.34–1.2.39 的所有响应都只有 `ready`，缺少 `configured`，因此框架持续轮询约 20 秒后终止插件。
  - 现在该接口固定返回 `{"ready":true,"configured":true}`，并保留 `X-Mengka-Managed-Ready` 响应头。
  - 移除无用的健康格式轮换与逐组日志，避免继续猜测。
- 同步更新 README、开发文档与三平台安装包。

## 升级说明

- 重新导入 1.2.40 Windows 包并启动。
- 日志应出现一次 `萌卡健康探活: ...`，之后约 20 秒内不再出现停止/退出，插件卡片状态应保持运行。
- 然后点击“管理”进入控制台。
- `127.0.0.1:5454` 是萌卡框架反代入口，插件实际使用日志中的 `MENGKA_PLUGIN_ADMIN_PORT`，无需手动绑定 5454。
