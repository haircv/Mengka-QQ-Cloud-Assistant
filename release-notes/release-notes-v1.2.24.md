# QQ云助手 v1.2.24

## 更新内容

- 新增 30 天免登录：
  - 登录页提供“30 天免登录”复选框，令牌登录和萌卡管理员登录都支持。
  - 勾选后会话写入本地 SQLite，Cookie 有效期 30 天；插件更新、重启后仍自动登录。
  - 手动“退出登录”会删除服务端会话并清除 Cookie，之后需要重新登录。
  - 不勾选时仍为普通会话，关闭浏览器或插件重启后需重新登录。
  - 不保存明文密码；浏览器可自行保存密码，服务端只保存随机会话令牌。
- Windows 自动启用增加 WMI 兜底：
  - 启动助手依次尝试任务计划、WMI `Win32_Process.Create`、独立进程。
  - WMI 由系统服务创建进程，不随插件进程被终止，适合萌卡替换文件时使用。
- 运行状态内存显示为“已用 / 总量 / 占率”；在线更新仅支持升级更高版本。
- 保留下载重试、更新后页面自动刷新和自动启用日志。

## 升级说明

- 已安装 1.2.23：在“系统 → 在线更新”检查并安装 1.2.24。
- 勾选 30 天免登录后，后续更新无需重新登录；手动退出登录除外。
- 更新后如未自动启用，可查看“在线更新 → 自动启用日志”，日志会显示任务计划 / WMI / 独立进程的启动方式。
