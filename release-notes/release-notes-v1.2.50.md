# QQ云助手 v1.2.50

## 更新内容

- 控制台启动流程优化：
  - 增加启动遮罩，先判定反代/登录模式，避免登录页或控制台闪屏。
  - 从萌卡插件卡片“管理”反代进入时，直接以管理员会话进入，不显示登录页、退出按钮或“登录已失效/过期”提示。
  - 反代会话不可用时显示“请从插件卡片重新打开”的提示，不退回本地令牌登录。
  - 通过 IP+端口直接打开控制台时仍显示登录页；有效的 30 天登录会话可直接进入。
- 管理令牌日志：
  - 首次生成 `admin.token` 时输出 `admin / <令牌>` 和文件绝对路径。
  - 已有数据目录升级到 1.2.50 首次运行也会补输出一次，之后用 `.admin-token-logged` 标记避免重复。
- 同步更新 README、开发文档与三平台安装包。

## 升级说明

- 重新导入 1.2.50 并启动；已有数据目录会看到一次管理令牌日志。
- 从插件卡片“管理”进入应直接显示控制台，不再闪登录页。
- 通过 IP+端口访问仍按原有登录方式。
