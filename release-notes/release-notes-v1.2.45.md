# QQ云助手 v1.2.45

## 更新内容

- 回退管理端卡片功能，优先保证插件启动：
  - 三个平台清单恢复 `"runtime.admin": false`，萌卡不再执行 `/api/managed/health` 管理端健康检查。
  - 插件卡片不再显示“管理”入口，避免框架因健康检查未通过而终止插件。
  - 控制台继续监听 `0.0.0.0:18084`，本机与局域网访问方式不变。
  - 管理端反代、健康接口与身份代码保留，后续根据框架 `-debug` 日志继续定位。
- 同步更新 README、开发文档与三平台安装包。

## 升级说明

- 重新导入 1.2.45 Windows 包并启动；确认包内 `mengka-plugin.json` 为 `"version":"1.2.45"`、`"admin":false`。
- 插件应正常保持运行，不再出现“插件管理端未就绪”。
- 使用 `http://127.0.0.1:18084/` 或启动日志中的局域网地址登录控制台。
- 若萌卡缓存了旧清单仍显示“管理”，请重新导入或重启插件。
