# QQ云助手 v1.2.49

## 更新内容

- 优化在线更新登录体验：
  - 从萌卡插件卡片“管理”反代进入控制台时，后端会复用浏览器当前的萌卡管理员 Cookie 调用管理 API。
  - Cookie 会话有效时，点击“立即更新”不再弹出萌卡管理员账号/密码/验证码登录。
  - 仅当会话失效、切换管理员、或萌卡要求 `capability_change` 权限确认时，才要求重新登录或确认。
  - Cookie 只用于本次管理接口请求，不写入日志、不持久化。
- 同步更新 README、开发文档与三平台安装包。

## 升级说明

- 重新导入 1.2.49 并启动。
- 从插件卡片“管理”进入后，在线更新应直接复用当前萌卡管理员会话。
- 直接打开 18084 控制台时没有框架管理员 Cookie，首次更新仍需登录一次；之后可正常使用。
