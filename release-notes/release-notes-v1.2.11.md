# QQ云助手 v1.2.11

## 更新内容

- 红包新增“领取自己发送的红包”设置，默认开启；群内自己发出的红包也会进入自动领取流程，可在控制台关闭或使用指令 `开启领取自己红包` / `关闭领取自己红包`。
- 安装包命名去掉 `managed-native`，恢复为 `qq-cloud-assistant-<版本>-<平台>`，减少文件名长度。
- 萌卡管理员登录优化：串行化验证码获取，避免多个验证码请求导致验证码图片与 ID 不匹配；登录请求增加 Referer/XHR 头；修复“测试萌卡接口”会消耗验证码、导致随后登录 401 的问题。
- 指令总数 382 条。

## 升级说明

在控制台“系统 → 在线更新”检查到 1.2.11 后登录萌卡管理员并导入；也可手动导入对应系统的 `qq-cloud-assistant-1.2.11-*` 安装包，保留原数据。
