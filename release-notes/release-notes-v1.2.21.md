# QQ云助手 v1.2.21

## 更新内容

- 版本号符合萌卡要求的 `x.y.z` 三段格式，替代 `1.2.20.1`。
- 在线更新下载增加自动重试：单次 90 秒超时，最多 3 次，间隔 3/6 秒，降低 GitHub 网络波动导致“下载安装包失败”的概率。
- 提交更新后控制台会等待插件重启并自动刷新页面，不再需要手动刷新判断是否启动。
- 启动助手首次检查从 6 秒缩短到 3 秒，轮询间隔 1 秒，等待新版本时间延长到 3 分钟。
- 其他功能与 1.2.20 相同。

## 升级说明

- 已安装 1.2.20 或更早版本：在“系统 → 在线更新”检查并安装 1.2.21。
- 已安装早期 1.2.21 修订包：点击“重新安装当前版本”获取本次下载重试与自动刷新修订。
- 1.2.20.1 不会被萌卡接收，已标记为预发布；请勿使用该版本。
- 配置、日志、授权与红包账本保留；更新后如未自动启用，可查看“自动启用日志”。
