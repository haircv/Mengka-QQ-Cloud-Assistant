# QQ云助手 v1.3.4

## 更新内容

- **加速指令回复呈现全部会员签到项**：`查询加速` 的任务列表不再按 `Actionable()` 过滤展示，与萌卡管理端同一面板，会员签到 8 项全部列出（补齐此前缺失的 QQ大会员官网签到、分享QQ大会员官网、QQ大会员师徒打卡、浏览QQ空间访客页面、QQ大会员空间专属点赞）。每项标注归属会员与「成长值」，未完成项附框架 `execution_message`（如「未开通 QQ 大会员，无法领取此任务奖励」「未建立师徒关系，请先在 QQ 大会员页面完成师徒绑定」）。自动补挂仍按 `Actionable()` 跳过必然失败项，不做无谓调用。
- **状态标记统一 `[✅]` / `[❌]`**：已完成或已开启用 `[✅]`，未完成或未开启用 `[❌]`，覆盖查询加速任务列表、任务开关、电脑/手机在线与定时执行开关。执行结果保留管理端粒度：确认 `[✅]`、失败 `[❌]`、提交 `[提交]`、跳过 `[跳过]`。
- **修复「查询加速」当前等级偶发显示 0**：等级原先只读账号快照，而快照 `level` 仅在 `get_bot_list` 刷新时写入，`bot_online` 事件先建的占位条目、刚登录或尚未刷新的账号会是 0。现在快照无有效等级时回源官方 `get_bot_info` 取真实等级，仍取不到则显示「未知」，不再给出误导性的 0。
- **修复运行概览 QQ账号 / 协议实例数量虚高**：概览统计前先刷新框架 bot 列表，并跳过 `Stale` 快照条目（事件先建的占位实例、已从框架移除的实例）。此前 1 个 QQ 双协议 + 1 个事件占位会显示「QQ账号 2 / 协议实例 3」，修复后为「QQ账号 1 / 协议实例 2」，Linux 实例被移除后正确降为 1 / 1。两张卡片补充口径副标题「按 QQ 号去重」「同 QQ 多协议分别计数」：账号数按 QQ 去重、实例数按协议实例计数，同 QQ 多协议时实例数本就大于账号数，并非标签写反。
- **加速账号解析同步排除残留实例**：加速助手账号列表与安卓实例解析（`AndroidKey` / `DefaultKey`）跳过 `Stale` 条目，避免选中已移除实例，或让 `protocol_id=0` 占位条目把等级任务路由到 Linux 实例。
- 指令数量（399）、控制台模块（61）、清单 action（59）、权限体系与既有数据均不变。

## 升级说明

- 已安装 1.3.3 及更早版本可在线更新或手动导入 1.3.4。
- 已有数据目录的配置、卡密、红包账本与农场/加速设置均保留。
- 加速助手仅 Android 协议账号可用；Free 会员不可用、Plus 要求 QQ 等级 ≥ 32。
- 会员签到中「未开通」项现在会完整显示并标 `[❌]`，这是与萌卡管理端一致的正常呈现，开通对应会员后即可执行。
- 控制台为纯静态构建产物，更新后若浏览器缓存旧页面，请强制刷新一次（Ctrl+F5）。
