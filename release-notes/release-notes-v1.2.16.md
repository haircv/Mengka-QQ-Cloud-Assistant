# QQ云助手 v1.2.16

## 更新内容

- 在线更新导入完成后自动启用插件：
  - 通过萌卡 `/api/v1/plugins/managed` 查找刚导入的实例，并调用 `action=start` 启动。
  - 控制台提示“更新完成，插件已自动启用”；如启动失败会保留导入结果并提示手动启用。
- 红包领取兼容与重试增强：
  - 请求同时携带嵌套 `red_packet`、扁平红包字段以及 `sender_id` / `sender_uin`，兼容不同萌卡节点实现。
  - 详情查询未返回凭据时立即再查一次；领取凭据失败依次尝试“新凭据 → 无凭据自动获取 → 自己发送的红包延迟 1.2 秒再试”。
  - `state=6` 记录会标明凭据无效；自己发送红包的领取成功率受节点风控影响，重试可减少但无法保证 100%。
  - 类型识别改为：6/32/65536/1024 等明确 `channel` 优先，`channel=1/0` 再结合 `type`，修复拼手气红包被显示为普通红包的问题。
  - 日志新增红包类型、渠道和凭据是否存在，不输出令牌内容。
- 语音红包改用 Base64 上传音频，修复“本地文件仅允许指定媒体目录或已上传文件”；固定音频为 HTTP(S) 地址时直接交给萌卡拉取。
- 登录页新增强提示：萌卡管理端口不固定，不一定是 `127.0.0.1:7891`；无法连接时改用数据目录 `admin.token` 登录。验证码或连接失败时也会显示回退指引。
- 发布产物只保留当前版本安装包；GitHub 仓库 README 与各版本发布说明同步更新。

## 升级说明

- 已安装 1.2.15 的节点可直接在“系统 → 在线更新”安装 1.2.16，更新后插件会自动启动。
- 如果自动启动失败，控制台会提示原因，可在萌卡「插件导入」页手动点击启动。
- 语音红包无需再配置 TTS；默认使用内置 AI 语音，也可继续使用自定义 TTS 或固定音频。
