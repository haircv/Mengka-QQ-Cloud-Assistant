# QQ云助手 v1.2.19

## 更新内容

- 修复“CSRF 校验失败”：
  - 核对萌卡 3.0.3 管理端：前端仍使用 `XSRF-TOKEN` Cookie + `X-XSRF-TOKEN` 请求头，没有改名。
  - 插件后台现在会读取任意名称包含 `csrf`/`xsrf` 的 Cookie；没有令牌时先 GET 萌卡管理首页，让服务端补发 `XSRF-TOKEN`。
  - 写请求同时发送 `X-XSRF-TOKEN` 与 `X-CSRF-Token`；遇到 403 CSRF 时刷新 Cookie 后重试一次。
  - 独立启动助手复用同一套 CSRF 逻辑。
  - 插件控制台自身遇到 403 CSRF 时，会从 `/api/admin/profile` 刷新 CSRF 并自动重试；上传、恢复备份也适用。
- 保留 1.2.18 的红包嵌套请求修复与独立启动助手。

## 升级说明

- 1.2.18 → 1.2.19：在线更新后由启动助手自动启用。
- 1.2.17 或更早 → 1.2.19：由于旧版本没有启动助手，首次仍需在萌卡插件页手动启动一次。
- 如果控制台已登录但页面停留较久，升级后直接操作会自动刷新 CSRF，无需退出重登；若浏览器仍报错，刷新页面即可。
