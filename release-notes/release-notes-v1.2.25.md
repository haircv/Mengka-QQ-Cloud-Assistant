# QQ云助手 v1.2.25

## 更新内容

- 运行状态指令内存行精简为：
  - `内存：31.93 GB（占率 15%）`
- 局域网访问说明与提示：
  - “系统 → 控制台设置 → 监听地址”补充说明：仅本机填 `127.0.0.1`，局域网访问填 `0.0.0.0`。
  - 监听 `0.0.0.0` 时，启动日志会列出本机与局域网访问地址。
  - 仅监听本机时，启动日志会提示如何开启局域网访问。
  - 局域网访问需要放行防火墙 `18084/TCP`，修改监听地址后重启插件生效。
- 保留 30 天免登录、下载重试、自动刷新、WMI 自动启用兜底。

## 升级说明

- 在“系统 → 在线更新”检查并安装 1.2.25。
- 如需局域网访问，修改监听地址为 `0.0.0.0` 后重启插件，并放行端口；不建议直接暴露公网。
