# QQ云助手 v1.2.26

## 更新内容

- Linux 自动启用增加 cron/at 一次性任务兜底：
  - 启动助手依次尝试 `systemd-run`、`/etc/cron.d`、用户 crontab、`at`，最后才回退独立进程。
  - cron/at 由系统调度器启动，不随萌卡替换插件时的 cgroup 终止。
  - 一次性任务执行后会自行删除，避免重复运行。
- 启动助手每 10 秒在 `logs/autostart.log` 记录等待状态，便于确认是否存活。
- 保留 30 天免登录、运行状态内存精简、局域网监听提示、下载重试和更新后页面自动刷新。

## 升级说明

- 已安装 1.2.25：在“系统 → 在线更新”检查并安装 1.2.26。
- 1.2.25 的旧启动助手没有 cron 兜底，本次更新后如仍未自动启用，请手动启动一次 1.2.26；之后更新会使用 cron/at 兜底。
- 更新后如未自动启用，可查看“在线更新 → 自动启用日志”，日志会显示 systemd-run/cron/at/detached 的启动方式。
