# QQ云助手 v1.2.18

## 更新内容

- 红包领取恢复为上一版的请求格式：
  - `grab_red_packet` / `get_red_packet_info` 只提交 `group_id`、`sender_id`、嵌套 `red_packet` 和可选 `claim_token`。
  - 不再把 `channel`、`title` 等字段平铺到顶层，修复“channel 已移除，请使用 red_packet.channel”“title 已移除，请使用 red_packet.title”。
  - 凭据重试与自己红包延迟重试保留，但每次请求都使用嵌套格式。
- 在线更新自动启用修复：
  - 导入后只匹配 `release.plugin_id + 目标版本 + 节点` 的实例；旧版本仍在运行时不再误判为“已启动”。
  - 提交 `start` 后会等待实例进入运行/启动中状态，再返回成功。
  - 导入前复制当前程序并启动独立启动助手；即使萌卡替换文件时终止旧进程，助手仍会在后台等待新版本并调用 `action=start`。
  - 助手日志写入数据目录 `logs/autostart.log`；临时助手文件会在后续启动时清理。
- 发布产物只保留当前版本安装包；GitHub README、开发文档与发布说明同步更新。

## 升级说明

- **1.2.17 → 1.2.18 首次升级后仍需手动点击一次启动**：独立启动助手是在 1.2.18 中才加入的，旧版本执行这次更新时还无法启动它。手动启动 1.2.18 后，后续在线更新会自动启用。
- 如果自动启用仍失败，控制台会返回 `start_error`；可查看数据目录 `logs/autostart.log`，或到萌卡「插件导入」页手动启动。
- 红包功能已恢复嵌套请求格式，无需修改现有配置。
