# QQ云助手 v1.2.28

## 更新内容

- 仅版本号递增，用于验证 1.2.27 的双平台自动启用助手；功能与 1.2.27 相同。
- 本次更新由正在运行的 1.2.27 助手执行，会自动尝试 Windows 任务计划/WMI/wmic 或 Linux systemd-run/cron/at。
- `logs/autostart.log` 会记录平台与实际启动方式。

## 升级说明

- 已安装 1.2.27：在“系统 → 在线更新”检查并安装 1.2.28。
- 如果更新后仍未自动启用，请等待约 10 秒再判断，并查看“自动启用日志”中的平台/方式。
- 若日志显示 `detached（平台 windows/linux）`，说明该环境的系统调度方式均不可用，需要检查运行权限或安装 cron。
