# QQ云助手（qq-cloud-assistant）

**适用于萌卡 NT 3.0 的 QQ 云端助手插件，原生 IPC 运行，并自带 Web 管理控制台。**

QQ云助手把群管理、自动化、问答、定时任务、红包助手、点歌、本地授权和在线更新放在一个控制台里。插件以原生 IPC 子进程运行，由萌卡负责启动、停止和权限管理；控制台默认监听本机 `18084`。

当前版本：**1.2.12** · 380 条指令 · 59 个控制台模块 · 支持 Windows x64 / Linux x86_64 / Linux ARM64。

[下载安装包](https://github.com/haircv/Mengka-QQ-Cloud-Assistant/releases) · [更新日志](release-notes/README.md) · [问题反馈](https://github.com/haircv/Mengka-QQ-Cloud-Assistant/issues)

## 可以做什么

| 分类 | 功能 |
| --- | --- |
| 群管理与提示 | 踢人、禁言/解禁、上下管、全体禁言、解禁全部、群星/群信息、取码、复读、取直链、加群链接；入群/退群/被踢/被删提示与模板 |
| 自动化 | 防撤、自身撤回、艾特回复/禁言、秒赞秒评、点赞、互赞、表情回应、续火、自动说说、自动处理、名片、打卡、资料、备注、头衔、入群验证 |
| 问答 | 本群/好友/全局 × 精准/模糊，白名单、延迟、随机回复条数、关键词冷却 |
| 任务与群发 | 定时、循环、群发群/好友/群名片；任务持久化、进度查看和停止 |
| 红包助手 | 普通/拼手气/口令/专属/语音五类独立开关；群/人员/标题关键词包含或排除规则；期望门槛、拟人延迟、到账回复、监听名单、账本与排行 |
| 点歌与搜歌 | QQ音乐/网易云/酷狗多源搜索、选歌、链接/语音/音乐卡片回复、线路优先级与失败换源 |
| 本地授权 | 本地卡密生成/禁用/删除、群主兑换、分群授权与续期、代理配额、可选授权门禁；无授权站、无应用 ID、无心跳 |
| 在线更新 | 默认读取本仓库 GitHub Release；校验插件 ID、版本与 SHA256 后，在萌卡托管模式下通过管理员登录导入；通用功能提供“在线更新/检查更新/立即更新”指令 |
| 管理控制台 | 59 个目录驱动模块；群号联想下拉；主人/分管/黑名单只填写 QQ；响应式布局与短屏弹窗滚动 |

全部指令默认 **Lv5**。主人 QQ、机器人自身 QQ 默认可用；需要群主或管理员使用时，在控制台“权限 → 指令权限”单独下调对应指令。

## 下载与启动

| 系统 | 安装包 |
| --- | --- |
| Windows AMD64 | `qq-cloud-assistant-1.2.12-windows-amd64.zip` |
| Linux AMD64 | `qq-cloud-assistant-1.2.12-linux-amd64.tar.gz` |
| Linux ARM64 | `qq-cloud-assistant-1.2.12-linux-arm64.tar.gz` |

从 [Releases](https://github.com/haircv/Mengka-QQ-Cloud-Assistant/releases/tag/v1.2.12) 下载对应系统的压缩包，并在萌卡 NT「插件 → 插件导入」上传；每个 Release 同时提供 `SHA256SUMS`。

## 安装与更新

1. 在萌卡 NT「插件 → 插件导入」上传对应系统的安装包，选择节点并启动。
2. 打开插件控制台 `http://127.0.0.1:18084/`。运行在萌卡内时默认使用**萌卡管理员账号、密码、图形验证码**登录，也可切换为本地 `admin.token`。
3. 在「账号列表」确认账号与协议实例，在「主人」页填写主人 QQ（或直接使用机器人自身 QQ）。
4. 在「权限 → 指令权限」按需调整等级；全部指令默认 Lv5。
5. 旧版本无法启动时，直接导入新版安装包并保留原数据目录，无需先卸载。
6. 后续在控制台「系统 → 在线更新」检查版本。默认更新源就是本仓库 GitHub Release；下载后会校验插件 ID、版本和 `SHA256SUMS`，再调用萌卡托管导入接口。
7. “萌卡管理接口”填写 **Mengka 管理端 Web 地址**（如 `http://127.0.0.1:7891` 或反向代理域名），不是插件控制台 `18084`。可先点“测试萌卡接口”检查。

| 自动化 | 防撤、撤回、艾特、点赞、互赞、表情、续火、说说、自动处理、名片、打卡、资料、备注、头衔、验证 |
| 问答 | 本群/好友/全局规则、白名单、延迟、随机条数 |
| 任务与群发 | 定时、循环、群发、点歌、点歌线路 |
| 红包 | 五类开关、规则、监听名单、延迟/门槛/回复、账本与排行 |
| 授权 | 卡密、分群授权、代理、授权设置 |
| 权限 | 主人、指令权限预设 |
| 系统 | 日志、备份恢复、在线更新、控制台设置、能力、关于 |

## 说明

- 本仓库用于发布 QQ云助手安装包、更新说明和问题反馈。
- 在线更新会校验 `plugin_id`、版本与 `SHA256SUMS`，不会导入其他插件的安装包。
- 红包、账号与授权数据保存在用户数据目录，重新导入插件不会清空数据。
